# Hotfix: режим «Идеи в бюджет»

Добавлен отдельный сценарий для пользователя, который не знает направление, но знает бюджет и примерный период.

Примеры:

```text
из СПб куда угодно в августе до 50000
куда слетать из Москвы 10.08-20.08 до 60000
идеи из LED в июле до 40000 до 1 пересадки
```

## Как работает

1. Парсер `parse_ideas_query()` извлекает город отправления, бюджет и период.
2. Период может быть строгим диапазоном `10.08-20.08` или месяцем `в августе`.
3. Направление не требуется: используется curated pool `data/idea_destinations.json`.
4. `TravelpayoutsClient.search_ideas()` ищет дешевые билеты по пулу направлений.
5. `_diversify_ideas()` сначала берет максимум один лучший вариант на страну, а потом добивает слоты следующими дешевыми городами.
6. В Telegram появился отдельный пункт меню: `🎲 Идеи в бюджет: куда угодно`.

## Почему это отдельный режим

Это другой user intent: не «найди билет в X», а «предложи, куда вообще можно улететь за эти деньги». Для монетизации это сильный retention-сценарий: пользователь может регулярно смотреть идеи на выходные/отпуск и сохранять price alerts.
