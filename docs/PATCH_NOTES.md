## Hotfix: сохранена главная фича репозитория

Multi-city теперь означает не маршрут в заданном порядке, а unordered route optimization: пользователь указывает города, которые хочет посетить, а бот сам подбирает дешевый порядок посещения. Подробности: `ROUTE_OPTIMIZER_NOTES.md`.

## Round-trip UX hotfix

Обработан кейс `из СПб в Китай и обратно 06.07-14.07`: теперь `и обратно` распознается как round-trip intent, а не как часть направления. Один диапазон дат в round-trip режиме трактуется как даты поездки: первый день — вылет туда, второй — обратный вылет. Для гибких окон поддерживается формат `туда 06.07-08.07 обратно 14.07-16.07`.


## Update: Ideas in budget

Добавлен отдельный режим `🎲 Идеи в бюджет: куда угодно`:

- пользователь задает город отправления, бюджет и примерный период;
- направление не задается;
- поддержаны фразы `из СПб куда угодно в августе до 50000`, `куда слетать из Москвы 10.08-20.08 до 60000`;
- добавлен curated pool `data/idea_destinations.json`;
- выдача диверсифицируется по странам, чтобы показывать разные идеи, а не пачку однотипных городов;
- добавлены тесты парсера и diversity-ranking.

## Fixed final destination for Multi-city

Multi-city теперь поддерживает сценарий `origin → unordered stopovers → fixed final destination`:

```text
из СПб в Сидней посетить Ханой, Бангкок, Куала-Лумпур 06.07-25.07 по 2-4 дня
```

Оптимизатор перебирает только промежуточные города, а Сидней фиксирует последним. Также добавлены алиасы `Сидней/SYD`, `Вьетнам`, `Тай/Таиланд` для более естественных запросов. Подробности: `FIXED_FINAL_DESTINATION_NOTES.md`.
