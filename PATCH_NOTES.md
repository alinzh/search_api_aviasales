# Что сделано в UX-патче

## Основные изменения

- Добавлен новый пакет `flight_finder`.
- Добавлен Telegram UX с главным меню, быстрым поиском и discovery по стране/региону.
- Добавлен парсер запросов одной фразой.
- Добавлена локальная директория городов/стран/авиакомпаний.
- Добавлены карточки результатов с кнопкой «Открыть билет».
- Добавлена кнопка «Следить за ценой этого запроса».
- Добавлена SQLite-база для истории поисков и price alerts.
- Добавлен affiliate-marker/sub_id в ссылки.
- Добавлены `.env.example`, Dockerfile, docker-compose.
- Оставлены совместимые entrypoints для старой структуры.

## Ограничения

- Я не смог выполнить `git clone` из sandbox из-за DNS, поэтому архив собран как самостоятельная улучшенная версия/патч, а не как git diff поверх локального clone.
- Multi-city режим в этом архиве пока UX-заготовка: он распознаёт цепочку городов, но основной рабочий MVP — поиск одной фразой и country discovery.
- Для реального продакшена надо расширить `data/city2code.json` и `data/countries.json` полноценной базой городов.
